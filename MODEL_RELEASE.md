# Separate adapter release

The public source package does not contain the trained adapter, NVIDIA base weights, or tokenizer files. The BANKING77 adapter is archived separately with its checksum in [`results/BANKING77.md`](results/BANKING77.md). Publishing a model artifact is a separate decision from making this source repository public.

The [model card at the exact revision used here](https://huggingface.co/nvidia/Nemotron-Mini-4B-Instruct/tree/791833e92ebddb0bc2c1007f6d2b6764f886a2ae) includes NVIDIA's [August 2024 Community Model License](https://huggingface.co/nvidia/Nemotron-Mini-4B-Instruct/resolve/791833e92ebddb0bc2c1007f6d2b6764f886a2ae/nvidia-community-model-license-aug2024.pdf). Section 1.2 permits creation and distribution of derivative models with a copy of that agreement. Its definition of a derivative model includes adaptations. Section 2.2.1 requires prominent notices on modified files. The agreement also restricts production use and preserves NVIDIA's rights in the base model. This is a license reading for this research release, not a grant to relicense NVIDIA material under the repository's MIT license.

The pinned Hugging Face model card's YAML metadata links NVIDIA's [June 2024 Open Model License](https://developer.download.nvidia.com/licenses/nvidia-open-model-license-agreement-june-2024.pdf), while its body links the August 2024 Community Model License above. Both expressly permit distribution of derivative models, though their production-use conditions differ. The adapter package includes both exact texts and a notice satisfying the stated attribution and modification requirements; it makes no production-use claim. An adapter-only release should identify the exact base revision, the training data and attribution, the one-seed benchmark limits, the adapter checksum, and the fact that it is an independent modification. A merged checkpoint would also contain NVIDIA's original weights and needs its own explicit packaging and rights review.

The adapter-only package is hosted on the separate [Nemotron Mini 4B Banking](https://huggingface.co/arpjw/Nemotron-Mini-4B-Banking) Hugging Face model page. It contains the verified 92,325,848-byte SafeTensors adapter, its original PEFT configuration, a complete model card, attribution, checksums, and copies of both NVIDIA license texts referenced above. It does not contain tokenizer files, NVIDIA base weights, test references, predictions, or runtime receipts. Model-page visibility is controlled separately from this source repository.
