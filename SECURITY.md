# Reporting issues

This repository contains research scripts and no hosted banking service. It is not supported for production banking use.

For reproducibility defects or documentation corrections, open a [GitHub issue](https://github.com/arpjw/nemotron/issues). Do not attach credentials, private statements, or customer data. If an issue would expose sensitive information, use GitHub's private vulnerability reporting when available. Otherwise open an issue asking for a private contact channel without including the sensitive details.
